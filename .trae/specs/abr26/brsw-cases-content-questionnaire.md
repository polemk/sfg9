# Brazilian Software — Questionário de Conteúdo dos Cases

> **Objetivo:** Preencher os Showrooms da landing `/brsw/cases` com **4 peças de conteúdo por case** pra virar Instagram-gallery cheia (foto + texto + vídeo). Vossa Excelência abre cada app, grava/fotografa o sugerido, e o Ministro (ou eu) anexa via painel admin do Showroom.
>
> **Pré-requisito:** rodar o seed primeiro pra criar os 6 Showrooms vazios —
> ```bash
> rails runner "load Rails.root.join('db/seeds/brsw_showrooms.rb')"
> ```
>
> **Como usar esse doc:** abrir cada seção no device/máquina onde o app roda, seguir as 4 capturas sugeridas, anotar quais já foram feitas marcando `[x]` na caixa.

## Processo operacional

### Fase 1 — Seed no banco de prod
```bash
cd backend
rails runner "load Rails.root.join('db/seeds/brsw_showrooms.rb')"
```
Cria os 6 Showrooms com título/descrição/caption/URL. **Não cria media nem logo.** Rerun é seguro.

### Fase 2 — Vossa Excelência grava o conteúdo
Seguindo a checklist acima. Pra cada case, 4 peças (ou menos se algum conteúdo não fizer sentido ainda).

### Fase 3 — Upload via painel admin
O Showroom tem attach de `logo_dark`, `logo_light`, `avatar`, `avatar_secondary` e `has_many :media`. Usar `/admin/showrooms` (já existente no ai9) pra subir os arquivos. Quando a media estiver anexada e `active=true`, a landing `/brsw/cases` já mostra automaticamente via ShowroomPostWidget.

### Fase 4 — Iteração
Se o cliente do case pedir ajuste, re-upload só do arquivo afetado. Nenhum re-deploy de código necessário.

## Sobre cases adicionais do servidor secreto

Vossa Excelência mencionou que o SSH secreto em `172.17.16.88:3188` tem `/var/www/apps` e `/var/www/html` com apps antigos. Quando quiser incluir mais cases no showroom:

1. SSH no servidor secreto
2. Fazer `ls /var/www/apps /var/www/html` pra listar
3. Identificar os que ainda fazem sentido mostrar (negócios vivos, não descontinuados)
4. Me passa a lista, eu adiciono ao array `BRSW_CASES` do seed, Vossa Excelência roda de novo e os novos caem no banco.

Sugestão de filtro pra não mostrar lixo histórico:
- Tem CNPJ do cliente vivo? ✓
- Ainda dá pra acessar a URL em prod? ✓
- Tem alguma coisa visualmente interessante pra mostrar? ✓
- A gente assinaria o contrato hoje com esse cliente? (proxy de qualidade)

Se todos os 4 = sim, vale entrar como DROP. Se não, fica de fora.
