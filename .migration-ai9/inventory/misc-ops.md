# Inventário — domínio residual (430–459) & operacional/config (600–639)

Unidade de **varredura final**: tudo que sobrou depois que as unidades de domínio
grandes (auth, projetos, recebíveis, risco, renegociações, indicadores, temas,
console, engines, dados, jobs, integrações) fecharam seus escopos.

**Convenção de ID usada aqui** (igual à de `public-site.md`): a numeração recomeça
no início da faixa **por prefixo** — `BE-430…`, `FE-430…`, `DB-430…` para a Parte A e
`OPS-600…` para a Parte B. O ID é a string completa (`BE-430` ≠ `FE-430`); a faixa
numérica é o que evita colisão **entre unidades**.

Fonte da verdade: `../sfg` (Rails 6.1.4 / Ruby 3.0.2, produto **Safegold**, módulo
`SFG::Application`). Nada foi modificado no legado.
